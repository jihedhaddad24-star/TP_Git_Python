# TP2 – Documentation du programme Python

## 1. Présentation

Ce projet est réalisé dans le cadre du TP2 : Rédiger le README.md du TP1.

L'objectif du programme est de créer un assistant de révision qui aide l'utilisateur à organiser ses révisions.

Le fichier `main.py` contient le programme Python. Il permet de demander des informations à l'utilisateur et d'afficher son objectif de révision.

## 2. Évolution du programme : V1 à V4

### V1 – Programme initial
Création du programme avec un message de bienvenue :
- Affichage du titre du programme.
- Affichage d'un message de bienvenue.

### V2 – Ajout du prénom
L'utilisateur peut saisir son prénom.
Le programme affiche un message de bienvenue personnalisé.

### V3 – Ajout de la matière
L'utilisateur peut saisir la matière qu'il souhaite réviser.
Le programme affiche le nom de la matière choisie.

### V4 – Ajout de la durée
L'utilisateur peut saisir la durée de sa révision en minutes.
Le programme affiche son objectif de révision avec la matière et la durée choisies.

## 3. Comment exécuter le programme ?

### Outils nécessaires
- Un ordinateur Windows.
- Python installé.
- Visual Studio Code.

### Étapes d'exécution

1. Ouvrir le dossier `TP_Git_Python` dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** (▶) en haut à droite.
4. Le terminal intégré s'ouvre.
5. Saisir le prénom demandé et appuyer sur Entrée.
6. Saisir la matière à réviser et appuyer sur Entrée.
7. Saisir la durée en minutes et appuyer sur Entrée.

Le programme affiche ensuite l'objectif de révision.

## 4. Commandes Git utilisées

Pendant le TP1, nous avons utilisé plusieurs commandes Git :

- `git init` : initialise un dépôt Git local.
- `git add main.py` : ajoute le fichier à la Staging Area.
- `git commit` : enregistre une version du projet dans l'historique.
- `git push` : envoie les modifications locales vers GitHub.
- `git pull` : récupère les modifications depuis GitHub vers le PC.
